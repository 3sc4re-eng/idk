  the shared action policy, Aim/Trigger and final output checks. Fresh snapshot,
  input and match validation remain separate. The legacy unverified menu signal
  is retired; a separately named raw-signal diagnostic is opt-in.
- Native Head/Neck sampling uses the real Reader route/attachment epoch, exact
  version guards, current actor/model/cache identities and bounded chronological
  observations. Warm reads share four A/leaves1/leaves2/B phases across demanded
  actors. Cached WORLD translations are not transformed by entity origin again.
- Only player Head/Neck are supported by the current acquisition/target accessor.
  Body/NPC aiming controls are excluded from the test UI/search while saved keys
  remain compatible. Body-only imports do not silently acquire a Head fallback.
  Existing Minion ESP demand remains independent. Trigger/Magnet share Aim point
  priorities and have separately effective distance overrides.
- World categories have live-renderer switches and optional custom label/icon/
  distance/color/size/range. Shared appearance inheritance and imported custom
  off/on retention use the existing per-game Settings/save/share paths. The
  change does not invent new breakable subtype mappings or reduce backend reads
  merely because one category is hidden.
- Prior menu/radar/ESP-copy reductions and cooperative framebuffer capture remain
  in the current composition. No unrelated full source block was replaced from
  an old exported proposal.
